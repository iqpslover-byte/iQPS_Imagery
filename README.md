# iQPS_Imagery

iQPS（株式会社QPS研究所）の小型SAR衛星 **QPS-SAR** が撮像した画像と、それを地図に重ねるための四隅の座標を置く。

[OP's LAB Maps](https://github.com/iqpslover-byte/OPs_LAB_Maps) が `raw.githubusercontent.com` 経由で `scenes.json` を読み、SAR IMAGERY メニューの「iQPS」から地図に重ねる。

**画像の著作権は iQPS に帰属する。** ここは地図に重ねて見るための置き場であり、権利を主張するものではない。

---

## scenes.json の形式

```json
{
  "scenes": [
    {
      "id": "kyoto",
      "name": "京都府 京都市",
      "file": "kyoto.jpg",
      "size": [6000, 4107],
      "corners": {
        "tl": [35.050074, 135.712931],
        "tr": [35.069699, 135.771825],
        "br": [35.017479, 135.800478],
        "bl": [34.997854, 135.741585]
      },
      "shot": "2026-08-29T13:40:12.8Z",
      "res": { "azimuthCm": 46, "rangeCm": 66 },
      "sat": { "num": "100243", "name": "QPS-SAR-13" },
      "mode": "spotlight"
    }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `id` | シーンの識別子 |
| `name` | 地点の名前（公式の命名） |
| `file` | このリポジトリ内の画像ファイル名 |
| `size` | 画像の画素数 `[幅, 高さ]` |
| `corners` | 四隅の `[緯度, 経度]`。**画像の画素の並び順**で `tl`=左上 `tr`=右上 `br`=右下 `bl`=左下 |
| `shot` | 撮像日時（UTC・秒は小数まで） |
| `res` | 分解能（cm・公式公表値）。`azimuthCm`＝アジマス `rangeCm`＝レンジ |
| `sat` | 撮像した機体（`num`＝カタログ番号・`name`＝機体名） |
| `mode` | 撮像モード |

`shot` 以降は省略できる。**撮像時の方位・仰角・距離・進行方位は置かない**。それらは `shot` と TLE から導ける値で、両方を持つと片方だけ古くなったときに同じ瞬間の値が2つできるため（実際に 22:40:13 と 22:40:08 の2つができた）。地図側は `shot` の時刻の衛星の位置から毎回導く。

画像を足すときは、ファイルを置いて `scenes` に1件加えるだけでよい。アプリ側の改修は要らない。

## 四隅の座標について

SAR画像は斜めから撮像するため、**北が上を向いておらず、方向によって縮尺も違う**。単純な回転や矩形では地図に重ならず、四隅を指定するアフィン変換が要る。

`corners` は必ず**平行四辺形**になる（アフィン変換の像なので、対辺は平行）。地図側はこの4点だけで正しく貼れる。

### kyoto

京都市街。賀茂川と高野川の合流点（出町柳）を含む。

| | |
|---|---|
| 画像 | 6000 × 4107（元画像そのまま・再圧縮なし） |
| 地上分解能 | 東西 1.03 m/px ／ 南北 1.36 m/px |
| 北の向き | 画像の真上から**東へ 35.4°** |
| 画像上の東西軸と南北軸の交角 | **68.9°**（地上では直交） |
| 範囲 | およそ 8 km 四方・34.4 km² |

四隅は画像から実測した。**京都御所の築地塀**（実寸 453.2 m × 254.6 m）の四隅を読んでアフィン変換を組み、**京都御苑・二条城・下鴨神社の糺の森**の3つで重なりを確認している（基準から 2.5 km 離れた二条城でも合う）。

京都の街路は直交しているが、この画像上では 69° に潰れて写る。その角度をフーリエ変換で独立に測ったところ 69.0° で、アフィン変換から出た 68.91° と一致した。

撮像幾何もここから逆算できる。画像の右方向は地上で方位 67.9°、下方向は方位 155.8°（両者は地上で 87.9°＝ほぼ直交）。アジマス方向の方位 67.9° は、軌道傾斜角 42° の衛星が緯度 35.0° を北上するときの地上軌跡の方位（理論値 65.2°）と近く、**昇交パスでの撮像**と整合する。

### 撮像諸元（TLEから算出・2026-09-07）

| 項目 | 値 |
|---|---|
| 撮像時刻 | **2026-08-29 13:40:12.8 UTC**（22:40:12.8 JST） |
| オフナディア角 | **20.11°** |
| 入射角（地表側） | 21.84° |
| 京都から見た衛星の仰角 | 68.16° |
| 同 方位 | 335.66° |
| 直距離 | 612.1 km |
| 直下点 | 36.746°N 134.792°E（高度 571.9 km） |

秒は画像の向きで決めた。SAR画像の縦軸はレンジ方向＝視線の水平投影で、四隅から出した方位は 155.66°、つまり衛星は 335.66° にいた。TLEでその方位になるのが 12.8 秒。1秒で衛星は約 7.5 km 進み方位が約 1.8° 動くので、分の公表だけでは決まらない。

独立検証として、山地のレイオーバー（地理院DEM z=14 を画像のアジマス・レンジ軸に載せ、標高を入射角ぶん衛星側へ寄せて投影）から入射角 19.2° を得ており、TLEの 21.84° と手法の精度内で一致する。

★以前ここに書いていた「入射角 38.8°＝オフナディア角およそ 35°」は誤り。画素間隔の比から入射角は出せない（その比は画像のサンプリングで決まる）。

### shirahama

和歌山県白浜町。南紀白浜空港（現滑走路と旧滑走路）・白良浜・田辺湾を含む。QPS-SAR-18（SUSANOO-Ⅱ）のファーストライト。

| | |
|---|---|
| 画像 | 6000 × 4575（**オルソ補正版**・JPEG品質95で再圧縮。元画像そのものではない） |
| 地上分解能 | 画像の横 1.08 m/px ／ 縦 1.34 m/px |
| 北の向き | 画像の真上から**西へ 23.8°** |
| 範囲 | およそ 39.8 km² |

**オルソ補正した理由**：空港は標高約 90〜100 m の台地にあり、海岸は 0 m。SARでは高い所ほど衛星側へ倒れ込んで写る（ここでは標高 1 m あたり地上 1.5 m）ので、1枚の四隅（平面のアフィン変換）では海岸と空港を同時に合わせられない（空港が約 130 px ずれる）。国土地理院の標高（DEM10B・z=14）を約 75 m でならし、倒れ込みを戻してから貼っている。細かくならさずに戻すと、衛星側を向いた斜面が引き伸ばされて溶けたような筋になる。

四隅は画像から実測した。**現滑走路・旧滑走路の4つの端**（OSM）と、画像全体の**海岸線**（OSM・約2万点）への当て込みを、平面の変換（6値）と倒れ込み（2値）の同時推定で解いた。滑走路の4端の残差は各 6〜21 px、海岸線は中央値 19 px。地図に重ねて、白良浜の弧・突堤・北側の桟橋・海岸沿いの道路・両滑走路の中心線が乗ることを確認している。

### 撮像諸元（TLEから算出・2026-09-11）

| 項目 | 値 |
|---|---|
| 撮像時刻 | **2026-09-08 00:03:21.3 UTC**（09:03:21.3 JST） |
| オフナディア角 | **27.45°**（ナディア＝楕円体の法線） |
| 入射角（地表側） | 30.2° |
| 白浜から見た衛星の仰角 | 59.8° |
| 同 方位 | 23.75° |
| 直距離 | 659.2 km |
| 直下点 | 36.180°N 136.721°E（高度 577.7 km） |

秒は画像の向きで決めた。画像の縦軸（上＝衛星側）は地上で方位 23.75° を向く。TLEでその方位になるのが 21.3 秒で、この日の通過で衛星がいちばん近づく瞬間（仰角最大）と一致する。撮像を挟む2組のTLE（9/6 と 9/9 の元期）で解いて 0.03 秒差。倒れ込み量から独立に出した入射角 33.6° とも手法の精度内で合う。

### taal

フィリピン・ルソン島のタール火山（Volcano Island）。タール湖に浮かぶ火山島と、中央のメインクレーター湖、島の南部に並ぶ小さな火口湖を含む。

| | |
|---|---|
| 画像 | 6000 × 4134（**元画像のまま**・オルソ補正はしていない） |
| 地上分解能 | 画像の横 1.33 m/px ／ 縦 1.98 m/px |
| 北の向き | 画像の真上から**西へ 136.7°**（北は画面の左下寄り） |
| 範囲 | およそ 65 km²（7.98 km × 8.17 km） |

**オルソ補正をしなかった理由**：島の最高点は約 287 m あり、入射角 25° では最大 615 m（レンジ方向に 311 px）倒れ込む。白浜と同じ手順で戻そうとしたが、火口壁の傾斜が入射角を超えていて（レイオーバー）情報が重なっており、補正すると斜面が溶けた縦筋になって元画像より悪くなった。原理的に戻せないので、元画像のまま貼っている。湖岸とクレーター湖は標高が低く、補正なしでも地図と合う。

四隅は画像から実測した。島の**湖岸線**（OSM）に当てはめ、回転・縦横の画素間隔・平行移動を総当たりで探索してから詰めている。残差は中央値 13.5 m（元画像で約 7 px）。SARの影に飲まれた南岸は原理的に写らないので、拘束からは外した。検証として、島の内陸にある**4つの火口湖**（岸から 1.5 km 以上離れている）がすべてOSMの水域と重なることを確認している。

### 撮像諸元（TLEから算出・2026-09-12）

| 項目 | 値 |
|---|---|
| 撮像時刻 | **2026-09-08 17:13:26.3 UTC**（現地 09-09 01:13:26.3 PHT ／ 09-09 02:13:26.3 JST） |
| オフナディア角 | **22.85°**（ナディア＝楕円体の法線） |
| 入射角（地表側） | 25.03° |
| タール火山から見た衛星の仰角 | 64.97° |
| 同 方位 | 136.68° |
| 直距離 | 622.3 km |
| 直下点 | 12.420°N 122.517°E（高度 568.9 km） |

秒は画像の向きで決めた。画像の縦軸（上＝衛星側）は地上で方位 136.68° を向く。TLEでその方位になるのが 26.3 秒で、この日の通過で衛星がいちばん近づく瞬間（仰角最大 65.0°）とほぼ重なる。撮像を挟む2組のTLE（どちらも 9/8 の元期）で解いて **0.001 秒差**。

公表の「01:13」は**現地時間（PHT＝UTC+8）**。日本時間の 01:13 にタール上空を通る便は無く、時刻の読みを誤ると別の周回を拾う。
